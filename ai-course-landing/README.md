# صفحة هبوط: كورس الذكاء الاصطناعي للأعمال

صفحة هبوط احترافية عربية (RTL) في ملف HTML واحد مستقل — لا تحتاج أي بناء أو تثبيت.

## التشغيل

افتح الملف مباشرة في المتصفح:

```bash
open ai-course-landing/index.html      # macOS
xdg-open ai-course-landing/index.html  # Linux
```

أو شغّل خادمًا محليًا بسيطًا:

```bash
cd ai-course-landing && python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## المحتويات

- **Hero** مع بطاقة سعر وزر تسجيل ومؤشر ثقة (تقييمات + عدد المتعلمين)
- شريط شعارات + قسم إحصائيات
- **المميزات** (٦ بطاقات)
- **لمن هذا الكورس** (٤ شرائح جمهور)
- **المنهج** — أكورديون تفاعلي لـ ٦ وحدات
- **المدرّب** + إحصائياته
- **آراء الخرّيجين** (شهادات)
- **الأسعار** — ٣ باقات
- **الأسئلة الشائعة** — أكورديون
- **CTA** ختامي مع عدّاد تنازلي
- Footer كامل

## التخصيص

كل المحتوى نصّي تجريبي قابل للتعديل مباشرة داخل `index.html`. لتغيير الألوان عدّل متغيرات CSS في `:root` أعلى الملف (`--primary`, `--accent`, ...).

> المحتوى الحالي تجريبي (أسماء، أسعار، أرقام) — استبدله ببيانات كورسك الحقيقية.
